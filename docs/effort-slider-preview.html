已融合的 dsh-effort-slider 核心酷炫细节

  • 像素点阵能量火焰：56×6 独立发光像素格 + 0.90 帧间余晖拖尾 + 错峰点火波 + 三频正弦扰动 + 飞溅白炽火花 + 可分离 Bloom 辉光合成。
  • 无级丝滑拖动 + 弹性弹簧吸附：拖动时 0~100% 连续无级，能量前沿带弹簧惯性追随；松手后 Thumb 弹性吸附至最近档位并触发档位字微模糊上浮。
  • 拖拽跟随点光源与微按压反馈：按下时滑块缩放至 0.91× 并点亮动态色温光环，轨道内径向点光源实时追随指针。
  • 底部「思考·XX」胶囊常驻着色：收起面板后，输入框胶囊仍保留当前档位的主题色点与微光边框，一眼识别当前算力档位。
  • 自动默认（Default）专属极光呼吸波：选择「默认」时轨道呈现柔和流动的冰青自适应扫描波，一旦拖动轨道自动接管为显式档位。

利用 C# .NET 10 + 原生 WPF 能做到什么程度？（100% 等效还原，零 WebView2）

零新增 NuGet 包 单文件体积 +0 KB 0 字节/帧 GC 收起后 0% CPU 休眠

1. 像素火焰 + Bloom 引擎

使用 WPF 原生 WriteableBitmap (Bgra32) + CompositionTarget.Rendering（与 DWM 垂直同步 60fps）。 轨道只有 56×6 = 336 个像素单元，用预分配 float[] 缓冲区在 .NET 10 上运行完整三阶段算法（余晖衰减 → 火焰/火花模拟 → 可分离 Bloom + Tone Mapping），单帧耗时 < 0.25 ms，直接 WritePixels 零 GC 上屏。

2. 点光源、辉光边框与微动效

卡片外圈辉光用底层 Border + BlurEffect；拖拽点光源用 RadialGradientBrush 动态更新 GradientOrigin；滑块按下缩放与松手吸附用 ScaleTransform + 阻尼弹簧步进；标题档位文字切换用原生 Storyboard (BlurEffect + TranslateTransform + Opacity) 实现丝滑微模糊浮现。

3. 完美贴合现有 MVVM 与性能红线

封装为独立复用控件 ReasoningEffortSlider.xaml，直接双向绑定现有的 AiReasoningEffort 枚举（AiAssistantDrawerControl 浮层与 AiAssistantPage 设置页共用一套）。Popup.Closed 与 IsVisibleChanged 自动解绑渲染循环，严格遵守项目 UI 线程零阻塞约束。
