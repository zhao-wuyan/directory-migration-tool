# 目录迁移工具调试流程

## Goal

在 Windows 上启动带控制台的 Debug 构建，观察一键迁移配置加载日志，而不执行真实迁移。

## Prerequisites

- Windows 与兼容 net8.0-windows10.0.19041.0 的 .NET SDK。
- 若选择 VS Code 调试，需 coreclr 调试支持。

## Steps

1. 在仓库根目录执行 `dotnet run --project MoveWithSymlinkWPF/MoveWithSymlinkWPF.csproj -c Debug`。
2. 或选择 `.vscode/launch.json` 的 `.NET Core Launch (console)`；附加已有进程使用 `.NET Core Attach`。
3. 打开一键迁移页，观察控制台 `QuickMigrateViewModel: LoadConfigAsync started` 与配置加载结果。不要点击迁移、还原或修复。

## Expected Outcome

Debug 配置使用 Exe 输出类型，DEBUG 条件编译启用控制台日志；日志反映配置加载成功或失败。以上命令来自现有项目配置，本次 init 未运行 WPF 应用，不声称应用烟测通过。

## Common Pitfalls

- Release 配置禁用调试符号且不包含 DEBUG 条件日志，不能用其验证此日志路径。
- Debug 入口启动不需要执行迁移；不要为获得日志而操作用户真实目录。
